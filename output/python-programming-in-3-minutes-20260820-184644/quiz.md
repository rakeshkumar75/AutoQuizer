## Question 1
Who created Python and in what year was it invented?

1. Guido van Rossum in 1991
2. James Gosling in 1995
3. Bjarne Stroustrup in 1983
4. Shad Sluiter in 2001

Answer: Option 1
Explanation: Python was invented in 1991 by Guido van Rossum with an emphasis on code readability and simplicity.

## Question 2
Which design philosophy primarily sets Python apart from many other programming languages?

1. Complex syntax and heavy boilerplate
2. Simplicity and readability
3. Manual memory management
4. Strict low-level memory addressing

Answer: Option 2
Explanation: Python stands out because of its simplicity and readability, using plain English syntax to be beginner-friendly.
